# hxwl-11 双眼视功能复训排程

在眼科验光记录基础上扩展的双眼视功能评估与复训排课系统。

## 业务规则

- **每次评估登记**：患者、远距隐斜（5m）、近距隐斜（33cm）、调节幅度（D）、集合近点 NPC（cm）。
- **异常判定（任一即异常，确认后进入「训练待复核」）**：
  - 调节幅度低于患者年龄下限：`15 − 0.25 × 年龄`（D，Hofstetter 最小幅度公式）；
  - 集合近点超过 `10cm`。
- **排课前置**：异常评估须填写训练方案，方案保存后进入「待排课」才可排课；正常评估判定「评估合格」，无需复训。
- **唯一占用**：同一训练位时段（日期 × 时段 × 训练位）只能排一人。
- **已排课改检查值**：只能走「更正」，更正时先释放原时段，再生成新版本。
- **冻结与版本**：评估确认后冻结，不可直接编辑；更正必须填写原因，系统新建同链 `version+1` 版本（待确认），旧版本完整保留旧值并标记「已更正」。
- **刷新一致性**：状态每次写入及页面加载时都经 `reconcile` 修复，保证评估、排课、占用、版本链一致（localStorage 持久化）。

## 分层架构（数据 / 规则 / 页面分开）

```
src/
├─ data/                 数据层：类型、目录、种子、持久化（无规则判断）
│  ├─ types.ts           领域模型
│  ├─ catalog.ts         训练位/时段目录与周课表生成
│  ├─ seed.ts            演示数据
│  └─ storage.ts         localStorage 读写
├─ rules/                规则层：纯函数状态迁移，不依赖 React
│  ├─ clinical.ts        年龄下限、NPC 阈值、单项判定
│  ├─ assessments.ts     登记/确认/复核/更正/一致性修复
│  ├─ scheduling.ts      可排课判定、占课、取消、释放
│  └─ versionChain.ts    版本链选择器
├─ state/                接线层：reducer 调用规则 + reconcile + 持久化
│  ├─ store.ts
│  └─ StoreProvider.tsx
└─ ui/                   页面层
   ├─ pages/             评估登记 / 复训排课 / 占用台账 / 版本链
   └─ components/
```

## 技术栈

React 19 + Vite + TypeScript + CSS（无额外运行时依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111；页面右上角「恢复演示数据」可重置。
